ALWAYS present choices as labeled options (A, B, C) — never yes/no. This is your explicit preference.

**Why:** Labeled options give the user clear, comparable choices. Yes/no questions hide alternatives and bias toward the presented option.

**How to apply:** When presenting any decision point, structure as 2-4 labeled options with one-line descriptions. Use AskUserQuestion when available.
