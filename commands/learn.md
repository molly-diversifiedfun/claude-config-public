Save learnings from this session to long-term memory.

Usage: /learn [topic]

This will:
1. Summarize key learnings, patterns, and decisions from the current session
2. Save them to `~/.claude/memories/[date]-[topic].md`
3. Include:
   - What was built or changed
   - Architecture decisions and their rationale
   - Gotchas, bugs found, or patterns discovered
   - Libraries or APIs used and their quirks
4. Future sessions can reference these memory files for context

Example: /learn supabase row-level security patterns
Example: /learn vite config gotchas
